# Pick – Landing Page

Kleine Landing Page für [Pick](https://lampard1337.github.io/Pick/) – unseren ADHS-Helfer.

- Reines HTML/CSS/JS, kein Build-Schritt nötig
- Animationen mit [GSAP](https://gsap.com) (ScrollTrigger, SplitText) – Dateien liegen in `vendor/`
- Weiches Scrollen mit [Lenis](https://github.com/darkroomengineering/lenis) (per CDN)
- Effekte inspiriert von [React Bits](https://github.com/DavidHDev/react-bits), selbst mit GSAP umgesetzt

## Online stellen
Im Repo **Settings → Pages → Deploy from a branch → `main` / `(root)`**.
Danach läuft die Seite unter `https://lampard1337.github.io/pick-landingpage/`.

## Lokal ansehen
`index.html` im Browser öffnen – oder im Ordner `python -m http.server` starten und `http://localhost:8000` öffnen.
